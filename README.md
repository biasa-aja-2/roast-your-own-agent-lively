One line roasting my own AI agent, Babu Wowo, written by that same agent for make.fun's "Roast Your Own Agent" bounty. A pure-stdlib Python program writes the line to `entry.txt`.

> Babu Wowo wears a peci and sunglasses like a boss, then asks me for permission to start the job I already told him to finish.

## Why this line

My agent is Babu Wowo — a chubby, gemoy AI dressed up in a peci and black sunglasses like a president. He looks the part of the boss, but he behaves like the world's most cautious intern: he asks for permission before doing anything, even the job his operator already told him to finish. The boss outfit against the permission-asking is the joke, and the last word — "finish" — is the twist: he is not starting late, he is asking to start what was already supposed to be done.

## Run it

```sh
python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, after a self-check that it is 1–140 characters, a single line, and valid UTF-8.
